# Indicadores - QA — Painel de Indicadores de Qualidade

Espelho de fallback deste app, rodando via Docker no Hugging Face Spaces
enquanto o Streamlit Community Cloud está instável. Ver `FALLBACK_DEPLOY.md`
no repositório principal para o passo a passo de como este Space foi criado
e como mantê-lo atualizado.

**Importante:** este arquivo (com o bloco `title/emoji/.../app_port` no topo)
precisa se chamar exatamente `README.md` **dentro do repositório deste
Space** — é assim que o Hugging Face reconhece a configuração dele. Não
sobrescreva o `README.md` do repositório principal (GitHub) com este
arquivo — são propositalmente dois arquivos separados.
